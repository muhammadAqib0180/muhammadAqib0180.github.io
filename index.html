AI security

Untrusted text is an attack surface

Job posts, web pages and documents all end up inside prompts. I build the checks into the system instead of hoping the model behaves.

01 · inputDelimit and screen

External text is labelled as data and checked by a separate guard model before any agent acts on it.

02 · toolsLeast privilege

Each agent gets an allowlist of tools, so a hijacked agent can't reach what it was never given.

03 · actionsHumans approve side effects

Anything that sends, spends or posts waits for a person, and every claim is checked against evidence first.
